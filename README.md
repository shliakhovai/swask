# swask

Задачі у твоєму ритмі. Ця гілка містить український список задач за дедлайнами, створення, редагування та локальне збереження. Свайпи, офлайн PWA, синхронізація з Neon PostgreSQL і нагадування додаються в наступних PR.

## Запуск

Потрібен Node.js 24.

```sh
npm install
npm run dev
```

Відкрий адресу, яку покаже термінал. Локальні задачі працюють без налаштування зовнішніх сервісів.

Деталі: [розробка](docs/development.md), [архітектура](docs/architecture.md), [правила для агентів](AGENTS.md).
