# swask

Задачі у твоєму ритмі. Світлий офлайн PWA з українським інтерфейсом, списком за дедлайнами та режимом свайпів. Синхронізація з Neon PostgreSQL і нагадування додаються в наступних PR.

## Запуск

Потрібен Node.js 24.

```sh
npm install
npm run dev
```

Відкрий адресу, яку покаже термінал. Локальні задачі працюють без налаштування зовнішніх сервісів.

Для встановлення та перевірки роботи без мережі використовуй готову збірку:

```sh
npm run build
npm run preview
```

Деталі: [розробка](docs/development.md), [архітектура](docs/architecture.md), [PWA та офлайн](docs/pwa.md), [правила для агентів](AGENTS.md).
