# swask

Задачі у твоєму ритмі. Світлий офлайн PWA з українським інтерфейсом, списком за дедлайнами, режимом свайпів, синхронізацією через Neon PostgreSQL та push-нагадуваннями.

## Запуск

Потрібен Node.js 24.

```sh
npm install
npm run dev
```

Відкрий адресу, яку покаже термінал. Локальні задачі працюють без налаштування сервісів.

Для синхронізації запусти `npm run setup`, додай Neon connection string у `DATABASE_URL` файлу `.env` та перезапусти застосунок. Схема створиться автоматично під час першого під’єднання. Введи згенерований `SWASK_SYNC_KEY` у налаштуваннях на кожному пристрої. [Деталі Neon](docs/sync.md).

Свайпи: **← зроблено**, **→ наступне коло**, **↑ перенести на 1 / 3 / 7 днів**. Доступні також кнопки та клавіші зі стрілками. Перенесення рахується від пізнішої дати: сьогодні або поточного дедлайну.

Нагадування за замовчуванням — о **09:00**, час можна змінити. Для push із закритим застосунком потрібні працюючий сервер, HTTPS і дозвіл браузера. `npm run setup` підготує push-ключі автоматично. [Налаштування нагадувань](docs/reminders.md).

Для встановлення та перевірки роботи без мережі використовуй готову збірку:

```sh
npm run build
npm run preview
```
